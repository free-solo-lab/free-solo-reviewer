# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment, personal attacks and publishing other people's private information are not accepted.

Report unacceptable behavior privately to the maintainers through **Security → Report a vulnerability** in this repository, with “Code of conduct” in the title. Reports are kept confidential.
