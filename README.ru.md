# Reviewer — быстрый старт

Reviewer — локальное приложение для ревью пул-реквестов в Java/Kotlin Spring-сервисах: диаграммы вызовов, SQL, транзакции, контракты и тесты с привязкой к строкам кода. Анализ делает Codex, публикует ревью в GitHub только вы. Подробности — в [README](README.md).

> [!WARNING]
> **Это alpha-версия.** Reviewer в ранней разработке: функции, формат данных и настройки могут меняться между версиями. Если ревью важны, делайте копию папки с данными. О проблемах пишите в **Настройки → Обращения** или в [issues на GitHub](https://github.com/free-solo-lab/free-solo-reviewer/issues).

## 1. Установка на macOS

### Из DMG

Скачайте DMG и соответствующий файл `.sha256` из раздела **Assets** [последнего GitHub Release](https://github.com/free-solo-lab/free-solo-reviewer/releases/latest): `Reviewer-<version>-darwin-arm64.dmg` для Apple Silicon или `Reviewer-<version>-darwin-x64.dmg` для Intel. В папке загрузки проверьте образ командой `shasum -a 256 -c Reviewer-<version>-darwin-<arch>.dmg.sha256`, подставив имя скачанного файла. Релиз по тегу публикуется автоматически после успешных проверок обеих архитектур. Ручные запуски [macOS DMG](https://github.com/free-solo-lab/free-solo-reviewer/actions/workflows/macos-dmg.yml) сохраняют временные артефакты на 30 дней, без публикации релиза.

Откройте DMG, перетащите **Reviewer.app** на **Applications**, извлеките образ и запустите Reviewer из «Программ», Spotlight или Dock. Для обновления закройте приложение, скопируйте его в ту же папку «Программы» и выберите **«Заменить»** в диалоге Finder. История ревью и авторизация хранятся отдельно и сохраняются. Имя приложения постоянно для всех версий. Если Spotlight показывает несколько копий, извлеките смонтированные образы и проверьте папки старых сборок; пункт меню **Reviewer → Показать приложение в Finder** показывает запущенную копию.

Node.js и Codex CLI уже входят в приложение. Git и [GitHub CLI](https://cli.github.com/) нужно установить отдельно: `brew install git gh`, если используете Homebrew. Установщик ниже добавляет недостающие инструменты автоматически.

Приложение имеет полноценную подпись ad-hoc; её проверяют до упаковки и после тестовой установки. Подписи Apple Developer ID и нотарификации пока нет. Если macOS блокирует первый запуск, попробуйте открыть Reviewer, затем перейдите в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтвердите запуск. Подробности — в [инструкции Apple](https://support.apple.com/ru-ru/102445). Если разрешить запуск не получается, используйте установщик из исходников.

При ошибке после запуска появится нативный диалог с кнопками **«Показать логи»**, **«Скопировать диагностику»** и **«Закрыть»**. Логи `desktop.log` и `server.log` находятся в `~/Library/Application Support/Reviewer` или `REVIEW_STATE_DIR`; эти действия доступны и в меню Reviewer. Диагностика содержит версию, архитектуру, путь запуска и сведения об ошибке, без ключей и содержимого репозиториев. Ничего автоматически не отправляется. Блокировку macOS до старта программы приложение не может заменить собственным сообщением. Если macOS сообщает о повреждении, проверьте SHA-256 и повторно скачайте последнюю выпущенную версию.

### Автоматическая сборка и установка

Откройте **Терминал** (Spotlight → «Терминал»), вставьте строку и нажмите Return:

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/free-solo-lab/free-solo-reviewer/master/scripts/install-macos.sh)"
```

Скрипт работает на чистом Mac (Apple Silicon или Intel, macOS 13+): ставит недостающее — Homebrew, Git, Node.js 24, GitHub CLI, — собирает **Reviewer.app**, кладёт его в «Программы» и открывает. Homebrew один раз спросит пароль от Mac. Первая сборка занимает около пяти минут. Чтобы обновить приложение, запустите ту же строку ещё раз.

Для самостоятельной сборки DMG из клона выполните `npm ci`, затем `npm run desktop:dmg`. Результат — `release/Reviewer-<version>-darwin-<arch>.dmg`. Сборка выполняется на Mac нужной архитектуры. Команда `npm run desktop:dmg:smoke` проверяет образ и установленную копию во временной папке, не затрагивая ваши приложения и данные.

В v0.1.3 из приложения исключены дублирующие зависимости интерфейса, бинарники терминала для других платформ и неиспользуемые WASM-парсеры. На Apple Silicon DMG уменьшился с 389,4 до 315,4 МиБ — примерно на 19%. Состав упаковки и результаты измерений описаны в [desktop/README.md](desktop/README.md#package-contents-and-size).

## 2. Подключение GitHub

1. В баннере сверху нажмите **Войти в GitHub** (позже — меню пользователя слева внизу → **Добавить аккаунт…**).
2. Код скопируется сам, откроется github.com. Вставьте код и подтвердите доступ.
3. Для второго аккаунта (например, рабочего) повторите через **Добавить аккаунт…**. Если браузер уже вошёл в другой аккаунт, подтверждайте в приватном окне.

Аккаунт по умолчанию выбирается в меню слева внизу. Репозиторию можно назначить свой аккаунт в **Новое ревью**. Токены хранит GitHub CLI, а не Reviewer.

## 3. Подключение Codex

Нажмите **Подключить Codex** в баннере или в меню пользователя и выберите один из способов:

- **Войти через ChatGPT** — для тарифа ChatGPT, в который входит Codex. Код скопируется, откроется auth.openai.com: вставьте код и подтвердите.
- **API-ключ OpenAI** — вставьте ключ с [platform.openai.com/api-keys](https://platform.openai.com/api-keys), оплата по использованию.

Вход хранит сам Codex в `~/.codex/auth.json`. Codex CLI уже встроен в приложение, отдельно его ставить не нужно.

## 4. Первое ревью

**Новое ревью** → выберите локальный клон репозитория с GitHub → выберите PR → **Анализировать**.

## Важно знать

- Код выбранных репозиториев отправляется в OpenAI для анализа. Не используйте Reviewer для кода, который нельзя передавать внешнему провайдеру.
- Всё остальное хранится локально в `~/Library/Application Support/Reviewer`. Сервер слушает только `127.0.0.1`.
- Без нажатия **Отправить ревью** в GitHub ничего не публикуется.

## Версии

Версии следуют [Semantic Versioning](https://semver.org/lang/ru/) и помечаются тегами `vX.Y.Z`; все изменения — в [CHANGELOG.md](CHANGELOG.md). Текущая версия — в **Настройки → Общие → О приложении**.

- **Патч** (0.1.0 → 0.1.**1**) — только исправления и обновления безопасности, обновляться можно без подготовки.
- **Минорная** (0.1.1 → 0.**2**.0) — новые возможности; пока версия 0.x, также изменения формата данных, настроек или поведения. Перед обновлением прочитайте changelog и сохраните копию папки с данными.
- **Мажорная** (→ **1**.0.0) — первый стабильный выпуск; после него данные и настройки ломает только мажорная версия.

Вся линейка 0.x — альфа: до 1.0.0 в приложении виден значок **alpha**.
