# Reviewer — быстрый старт

Reviewer — локальное приложение для ревью пул-реквестов в Java/Kotlin Spring-сервисах: диаграммы вызовов, SQL, транзакции, контракты и тесты с привязкой к строкам кода. Анализ делает Codex, публикует ревью в GitHub только вы. Подробности — в [README](README.md).

> [!WARNING]
> **Это alpha-версия.** Reviewer в ранней разработке: функции, формат данных и настройки могут меняться между версиями. Если ревью важны, делайте копию папки с данными. О проблемах пишите в **Настройки → Обращения** или в [issues на GitHub](https://github.com/free-solo-lab/free-solo-reviewer/issues).

## 1. Установка на macOS

Откройте **Терминал** (Spotlight → «Терминал»), вставьте строку и нажмите Return:

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/free-solo-lab/free-solo-reviewer/master/scripts/install-macos.sh)"
```

Скрипт работает на чистом Mac (Apple Silicon или Intel, macOS 13+): ставит недостающее — Homebrew, Git, Node.js 24, GitHub CLI, — собирает **Reviewer.app**, кладёт его в «Программы» и открывает. Homebrew один раз спросит пароль от Mac. Первая сборка занимает около пяти минут. Чтобы обновить приложение, запустите ту же строку ещё раз.

## 2. Подключение GitHub

1. В баннере сверху нажмите **Войти в GitHub** (позже — меню пользователя слева внизу → **Добавить аккаунт…**).
2. Код скопируется сам, откроется github.com. Вставьте код и подтвердите доступ.
3. Для второго аккаунта (например, рабочего) повторите через **Добавить аккаунт…**. Если браузер уже вошёл в другой аккаунт, подтверждайте в приватном окне.

Аккаунт по умолчанию выбирается в меню слева внизу. Репозиторию можно назначить свой аккаунт в **Новое ревью**. Токены хранит GitHub CLI, а не Reviewer.

## 3. Подключение Codex

Нажмите **Подключить Codex** в баннере или в меню пользователя и выберите один из способов:

- **Войти через ChatGPT** — для тарифа ChatGPT, в который входит Codex. Код скопируется, откроется auth.openai.com: вставьте код и подтвердите.
- **API-ключ OpenAI** — вставьте ключ с [platform.openai.com/api-keys](https://platform.openai.com/api-keys), оплата по использованию.

Вход хранит сам Codex в `~/.codex/auth.json`. Codex CLI уже встроен в приложение, отдельно его ставить не нужно.

## 4. Первое ревью

**Новое ревью** → выберите локальный клон репозитория с GitHub → выберите PR → **Анализировать**.

## Важно знать

- Код выбранных репозиториев отправляется в OpenAI для анализа. Не используйте Reviewer для кода, который нельзя передавать внешнему провайдеру.
- Всё остальное хранится локально в `~/Library/Application Support/Reviewer`. Сервер слушает только `127.0.0.1`.
- Без нажатия **Отправить ревью** в GitHub ничего не публикуется.
